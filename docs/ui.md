这份 UI 设计文档基于 **高质感扁平风 (Premium Flat)** 的视觉标准进行推导。该风格在业内常被称为 **Neo-Brutalism (新粗野主义) 的现代改良版** 或 **Clean Flat 风格**。它通过高对比度的边框、克制的阴影、通透的色彩层级以及流畅的响应式栅格，来同时满足“极客感”与“生产力工具的高级质感”。

以下是为你量身定制的 UI 设计文档与 Markdown 结构草图演练。

# 个人网站 UI 视觉与交互设计文档 (UID)

## 1. 视觉规范 (Design Tokens)

为了确保 Claude Code 在编写 Tailwind CSS 时具有绝对统一的视觉表现，我们先定义标准的色彩与间距常数：

### 1.1 色彩调色盘 (Palette)

* **基础背景 (Background)**：`#f8fafc` (Slate-50) - 带来通透干净的画布感。
* **容器前景色 (Surface)**：`#ffffff` (Pure White) - 用于承载内容的卡片。
* **纯黑线条 (Stroke/Border)**：`#0f172a` (Slate-900) - 用于定义扁平线条，替代传统的浅灰边框。
* **品牌主调 (Primary)**：`#3b82f6` (Blue-500) - 用于后台 Chatter 右侧聊天气泡、主按钮。
* **交互激活态 (Active/Accent)**：`#22c55e` (Green-500) - 用于前台导航栏选中状态、在线指示灯。
* **文字主色 (Text Primary)**：`#1e293b` (Slate-800)。
* **文字次色 (Text Secondary)**：`#64748b` (Slate-500)。

### 1.2 阴影与圆角 (Shadows & Borders)

* **扁平高质感阴影**：摒弃大范围模糊的毛玻璃阴影，采用**硬朗、清晰的小投射阴影**。
* 导航选中阴影：`text-shadow: 0 2px 4px rgba(15, 23, 42, 0.15);`
* 卡片悬浮阴影：`box-shadow: 4px 4px 0px 0px #0f172a;` (扁平硬阴影)


* **圆角规范**：
* 大容器/外层卡片：`rounded-2xl` (`1rem` / `16px`)
* 按钮/胶囊履历/小组件：`rounded-full` 或 `rounded-lg` (`8px`)

## 2. 核心页面布局与交互设计

### 2.1 前台通用顶部导航栏

* **布局**：`flex justify-between items-center h-16 px-8 bg-white/80 backdrop-blur-md sticky top-0 border-b border-slate-900/10`
* **交互细节**：
* 未激活标签：文字颜色为 `text-slate-600`，悬浮时文字变黑。
* 激活标签：文字变为 `text-green-600 font-bold`，同时触发 `drop-shadow-sm` 效果（文字后方有一层克制柔和的淡色重影）。



### 2.2 后台聊天室工作台 (自适应响应式架构)

#### 2.2.1 PC 端布局 (屏幕宽度 $\ge$ 768px)

* **结构**：采用 `grid grid-cols-12 h-[calc(100vh-4rem)]` 分栏。
* **左侧会话栏 (cols-3 或 cols-4)**：固定宽度，右侧一条细分型边框。
* **右侧聊天主视窗 (cols-9 或 cols-8)**：占满剩余空间。

#### 2.2.2 移动端自适应布局 (屏幕宽度 < 768px)

* **状态机控制**：引入 React 状态变量 `const [activeSessionId, setActiveSessionId] = useState(null);`
* **视图外层容器**：`relative w-full h-full overflow-hidden flex`
* **会话列表层**：`w-full shrink-0 transition-transform duration-300`
* 当 `activeSessionId != null` 时，添加样式 `translate-x-[-100%]`（整栏向左滑出屏幕）。


* **对话视窗层**：`absolute top-0 left-0 w-full h-full transition-transform duration-300 translate-x-full`
* 当 `activeSessionId != null` 时，添加样式 `translate-x-0`（从右侧滑入并盖住屏幕）。
* 顶部导航栏左侧动态渲染一个 `← 返回` 按钮，点击执行 `setActiveSessionId(null)` 触发滑回动画。
